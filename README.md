# Augsburg Adventure Radius v6

Adds a new **Cheap Flights** layer using only Munich (MUC) and Memmingen (FMM) as eligible origins.

This first flight database contains 24 high-value destinations that can plausibly hit the user's $150 round-trip target on low-fare dates, led by the verified 2026 Memmingen network.

Flight pins are destination-level pins. Clicking one opens:
- route / airport
- planning airfare
- flight time
- ideal trip length
- destination cost level
- why it is worth flying there
- expandable major city attractions and major regional day trips

Important: airfare is dynamic. Displayed dollar amounts are planning floors/targets, not guaranteed live quotes. Where current carrier fare evidence was available, the card says so.
